# 📝 TODO App

A simple and responsive **To-Do List web application** built using HTML, CSS, and JavaScript. This application helps users organize their daily activities by adding new tasks and deleting tasks when they are no longer needed.

🔗 **GitHub Repository:** https://github.com/ShyamKumarChaurasiya/TODO-App

## ✨ Features

- ➕ Add new tasks to the task list
- ⌨️ Add tasks using the Enter key
- 🗑️ Delete tasks with a single click
- 🚫 Prevent adding empty tasks
- 🎨 Clean and modern user interface
- 📱 Responsive layout
- 🌈 Attractive gradient background
- ✨ Smooth hover effects and animations
- 🔤 Poppins font for a polished appearance

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, layout, animations, and responsive design
- **JavaScript** – Task creation, deletion, and DOM manipulation
- **Google Fonts** – Poppins typography
- **Font Awesome** – Add button icon

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/ShyamKumarChaurasiya/TODO-App.git
```

### 2. Navigate to the Project Folder

```bash
cd TODO-App
```

### 3. Run the Application

Open the `index.html` file in your preferred web browser.

You can also open the project using the **Live Server** extension in Visual Studio Code.

## 💡 How to Use

1. Enter a task in the input field.
2. Click the **Add** button or press **Enter**.
3. The task will appear in the task list.
4. Click the **Delete** button to remove a task.
